# Netflix Data Analytics and Visualization Project

## Project Overview

This project focuses on cleaning, analyzing, and visualizing Netflix content data using Python. The objective is to transform raw data into meaningful insights through data preprocessing and exploratory data analysis (EDA).

The project demonstrates practical skills in data cleaning, handling missing values, duplicate removal, visualization, and business insight generation.

---

## Objectives

* Perform data cleaning and preprocessing
* Handle missing values and duplicate records
* Conduct exploratory data analysis (EDA)
* Create meaningful visualizations
* Generate business insights from data
* Build a professional analytics project using Python

---

## Dataset

Dataset: Netflix Movies and TV Shows Dataset

Dataset contains information such as:

* Show ID
* Title
* Type (Movie/TV Show)
* Director
* Cast
* Country
* Date Added
* Release Year
* Rating
* Genre

---

## Technologies Used

* Python

## Data Cleaning Process

The following preprocessing steps were performed:

### Missing Values

* Director column filled with "Unknown"
* Country column filled with "Unknown"
* Cast column filled with "Not Available"
* Rating column filled using mode

### Duplicate Records

* Identified duplicate rows
* Removed duplicates to improve data quality

### Data Type Conversion

* Converted Date Added column into datetime format
* Extracted Year Added feature for trend analysis

---

## Exploratory Data Analysis

The following analyses were conducted:

### 1. Movies vs TV Shows Distribution

Analyzed the proportion of Movies and TV Shows available on Netflix.

### 2. Top Content Producing Countries

Identified countries contributing the highest amount of Netflix content.

### 3. Rating Distribution

Examined audience rating categories and content classifications.

### 4. Content Growth Over Time

Analyzed trends in Netflix content additions over the years.

### 5. Genre Analysis

Identified the most popular content categories and genres.

## Key Insights

* Movies significantly outnumber TV Shows on Netflix.
* The United States contributes the highest amount of content.
* Netflix experienced rapid content growth after 2016.
* Drama and Comedy are among the most common genres.
* Content ratings indicate a strong focus on mature audiences.
